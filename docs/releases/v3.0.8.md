# KnolTeacher v3.0.8

## 목적

v3.0.8은 v3.0.7 안정화 기반 위에서 **로컬 설정 저장의 신뢰성**과 **GitHub Release 단일파일 업데이트 계약**을 강화하는 릴리스다.

## 주요 변경

### 1. ConfigService 안전 로컬 저장 확대

- `ConfigService`의 설정 JSON 15종을 `SafeLocalJsonStore` 기반으로 전환했다.
- 저장은 `SafeLocalFileStore.WriteAllTextAtomic`을 사용해 temp → flush → atomic replace 순서로 처리한다.
- 기존 파일명과 JSON schema는 변경하지 않는다.
- 학생/교사 데이터를 원격 서버나 클라우드로 전송하지 않는다.

### 2. JSON 손상 감지 및 local backup 복구

- primary 파일은 단순 읽기 성공이 아니라 JSON 역직렬화 성공까지 검증한다.
- primary가 손상되거나 읽을 수 없을 때 `.bak`도 별도로 검증한다.
- 정상 backup이 있을 때만 해당 값을 사용하고 primary를 best-effort로 복구한다.
- primary와 backup이 모두 유효하지 않으면 기존 기능별 기본값 정책으로 안전하게 fallback한다.

### 3. 자동 테스트 확대

- SafeLocalFileStore 기존 테스트 유지
- SafeLocalJsonStore 테스트 추가
  - 정상 round-trip
  - 손상 primary + 정상 backup 복구
  - primary/backup 모두 손상
  - primary 없음 + backup만 존재
- ConfigService integration 테스트 추가
  - 실제 저장/재로드
  - 손상 timer settings 복구
  - v3.0.7의 기존 JSON key/file 호환

### 4. Release asset 이름 보장

v3.0.7에서 로컬 publish 결과는 `놀티쳐.exe`였지만 GitHub Release asset이 `default.exe`로 변환되는 현상이 확인됐다.

v3.0.8부터 Release workflow는 GitHub Upload API를 직접 사용한다.

릴리스 완료 조건:

- GitHub Release asset 개수 = 1
- asset 이름 = `놀티쳐.exe`
- local publish 파일 크기 = GitHub asset 크기
- GitHub digest가 제공되는 경우 SHA-256 일치
- 실행 파일 embedded FileVersion = `3.0.8`

## 업데이트 호환성

- 기존 v3.0.6 updater는 최신 Release의 첫 `.exe` fallback을 지원하므로 v3.0.8로 직접 업데이트할 수 있다.
- v3.0.7 updater는 정확히 `놀티쳐.exe`를 선택하도록 강화되어 있으므로 v3.0.8의 정확한 asset 이름을 사용한다.
- 기존 설치본은 별도 설치 프로그램 없이 `버전 확인 → 업데이트 → 자동 재실행` 흐름을 유지한다.
