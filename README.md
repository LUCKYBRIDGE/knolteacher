# 🏫 놀티쳐 (KnolTeacher) v3.0.5

> 대한민국 교사를 위한 Windows 올인원 수업·학급경영·스마트보드 데스크톱 애플리케이션

현재 주력 구현은 **C# / .NET 8 / WPF** 기반이다. 이전 Python/CustomTkinter 구현은 `legacy-python/`에 보관하며 신규 기능 개발 기준으로 사용하지 않는다.

## 다운로드

최신 사용 버전은 GitHub Releases에서 받는다.

- 최신 릴리스: **v3.0.5**
- 플랫폼: Windows 10/11 x64
- .NET 런타임: self-contained 배포이므로 별도 설치가 필요하지 않는다.
- WebView2를 사용하는 웹 기능은 Windows의 Microsoft Edge WebView2 Runtime을 사용한다. 일반적인 최신 Windows 10/11 환경에는 설치되어 있으나, 제거된 PC에서는 별도 설치가 필요할 수 있다.

> 개발자가 로컬에서 `publish.bat`을 실행하면 배포 파일은 `dist-net\놀티쳐.exe`로 정리된다.

## v3.0.5 주요 개선사항
- 📅 **구글 캘린더 스타일 날짜별 개인 일정 & 메모 시스템 구축**:
  - 기존 학사일정 달력 위젯 하단의 거대한 공백 공간을 100% 활용하도록 전면 재설계.
  - 선택한 날짜에 교사가 수업 계획, 학부모 상담, 동료 교사 회의, 수행평가 일정, 개인 메모 등을 자유롭게 등록·수정·삭제 가능.
  - 5가지 컬러 라벨(업무, 수업, 상담, 중요, 개인) 태그 및 종일/시간별(시:분) 정밀 일정 관리.
- 🔔 **스마트 사전 알람(차임벨 + 토스트 HUD 알림) 엔진 연동**:
  - 일정 시작 정각 및 사전(5분, 10분, 15분, 30분, 1시간, 1일 전) 알람 옵션 제공.
  - 1초 단위 스케줄러(`SchedulerService`)와 백그라운드 연동되어 수업 중이나 다른 작업 중에도 부드러운 주의 차임벨 소리와 함께 우측 하단 토스트 팝업으로 교사에게 정확히 안내.
- 🔴 **달력 그리드 듀얼 도트(Dot) 인디케이터**:
  - 학교 NEIS 공식 학사일정 도트(주황색)와 교사 개인 일정 도트(파란색/지정색)가 나란히 표출되어 한눈에 일정을 파악 가능.
- 🗂️ **선택일 상세 vs 월간 학사일정 탭 전환 뷰**:
  - 상단 탭 라디오 버튼을 통해 `[📅 선택일 일정·메모]`와 `[🏫 이번달 학사일정]`을 원클릭으로 손쉽게 교차 확인.
  - 일정이 없는 날짜에는 친절한 엠티 스테이트(Empty State) 카드와 즉시 추가 버튼 제공.
- 💾 **데이터 영구 보존 (`calendar_events.json`)**:
  - 모든 사용자 일정과 메모, 알람 발송 여부 데이터가 안전하게 자동 로컬 영구 저장.

  - 놀보드 네온 D-Day 위젯(`DDayWidgetView`)과 메인화면 D-Day 카드가 `dday_config.json`을 통해 실시간 동기화.

  - 모둠 수에 따른 최적의 2열/3열/4열 자동 그리드 레이아웃 및 점수/모둠 수 영구 보존.

- ⏱️ **위젯 크기 최적화 및 오버타임 카운트다운**:

## v3.0.3 주요 개선사항
- 🏫🎒 **수업 구분 2원화 (교실수업 vs 이동수업)**:
  - 특별수업, 전담수업 등 복잡한 구분을 없애고 **`교실수업`**과 **`이동수업`** 2종류로 단순화 및 일원화.
  - 알람 설정에서 **교실수업 기본 알람**(기본 5분 전)과 **이동수업 기본 알람**(기본 10분 전)을 독립적으로 설정 가능.
  - 특정 이동수업(체육, 과학실, 음악실 등)에 대해 개별 교시별 분·초 알람 시간 수동 미세조정 지원.
  - 시간표 뱃지도 `🏫 교실 5분전` (에메랄드)과 `🎒 이동 10분전` (인디고)으로 직관적 표출.
- 🔔 **작업표시줄 시스템 트레이(숨김 아이콘) 정식 아이콘 반영**:
  - 윈도우 작업표시줄 숨김 아이콘 트레이에 기본 빈 창 아이콘 대신 놀티쳐 고유의 책·새싹 마스코트 아이콘(`app_icon.ico`) 정상 표출.
- 🏁 **32종 동물 뽑기 레이스 대폭 고도화**:
  - **구조물 비주얼 투명화**: 범퍼 타원 그림자, 통나무 하단 그림자 및 중앙 리벳 테두리를 완전히 제거하여 순수 투명 에셋만 깔끔하게 표출.
  - **와장창 깨지는 빗살무늬 토기 코스 전역 배치**: 선두 캐릭터와 충돌 시 도자기가 10개 파편으로 와장창 깨지며 사라지는(`Break`) 효과 구현 및 트랙 전역(초반, 슬라롬, 고인돌, 원시림, 결승 관문 등 11개)에 배치.
  - **빗살무늬 토기 충돌 반발력 대폭 상향**: 충돌 시 캐릭터가 큰 반경으로 시원하게 튕겨 올라가며(-460px/s, ±240px/s) 어지러움 연출이 발생하여 후발 주자들의 극적인 역전 레이스 연출.
  - **미니맵 클릭 & 드래그 실시간 시점 이동**: 좌측 세로 미니맵 코스 어디든 마우스로 클릭하거나 드래그하면 즉시 해당 위치로 카메라 시점(뷰포트)이 부드럽게 이동하며, 언제든 `[🥇 1등 복귀]` 버튼을 통해 선두 추적으로 복귀 가능.

## v3.0.2 주요 개선사항
- 칠판보드(수업 칠판/화면 판서 스튜디오) **2줄/1줄 스마트 반응형 툴바**:
  - 교실 노트북 및 스마트TV/전자칠판(1366x768 또는 1920x1080 125%~150% 배율) 환경에서도 우측 버튼(`지우기`, `판서 종료`, `저장` 등)이 **절대 잘리지 않도록 2줄 스마트 레이아웃** 기본 적용.
  - 상단 `[↕ 1줄로 / 2줄로]` 전환 버튼을 통해 언제든 1줄/2줄 표시 모드를 자유롭게 전환 가능.
- 칠판보드 **도구창 접기/펴기 (화면 극대화)**:
  - `[▲ 접기]` 버튼(또는 도구창 더블클릭) 클릭 시, 화면 상단에 초슬림 미니 플로팅 뱃지(`[▼ ✏️ 판서 도구 펼치기 | 💾 저장 | ✕]`, 높이 32px)로 축소되어 칠판 전체를 막힘 없이 넓게 필기·수업 가능.
  - 마우스 드래그를 통해 도구창을 화면 어느 곳이든 자유롭게 이동 가능.
- **기본 파일 저장 폴더 사전 설정 시스템**:
  - 기존 다운로드 폴더 기본 동작 외에, 교사가 원하는 저장 경로(바탕화면, 내 문서, D드라이브 수업폴더 등)를 사전 설정할 수 있는 전용 설정 탭(`📁 저장 위치 및 파일 관리`) 제공.
  - 판서 화면 내 `[📁 폴더 열기]`, `[⚙️ 저장위치]` 버튼을 통해 현재 저장 위치를 즉시 확인·열기 및 변경 가능.
  - 학생 명렬표, 과제 체크리스트, 누가기록, 나이스 엑셀 양식, 전자서명 등 앱 내 모든 파일 저장·내보내기 대화상자가 설정된 기본 폴더로 자동 연결.

## v3.0.1 주요 개선사항
- ⏱️ **타이머 종료 시 화면 창 유지 & 초과 시간 카운트**: 카운트다운 타이머가 0:00에 도달하더라도 창이 자동으로 사라지지 않고 초과 지연 시간(`0:00 (-0:15)`)을 붉은색으로 계속 표시하며, 교사가 ESC나 닫기 버튼을 누를 때까지 학생 화면에 유지.
- 🎒 **교시별 알람 수정·삭제 & 이동수업·전담수업 이동시간 프리셋**: 시간표 각 교시마다 개별적으로 알람 켜기/끄기(삭제) 지원. 이동 수업(10분 전), 특별실(7분 전), 전담 수업(5분 전) 등 이동시간을 반영한 원클릭 프리셋 및 시간표 행 내 알람 뱃지 제공.
- 🏫 **시군구 단위 정밀 지역 연동 (`강릉(우리학교)`)**: NEIS 학교 도로명주소 및 교육지원청 분석을 통해 "강원" 대신 **"강릉(우리학교)"** 등 시군구 단위로 정밀 표출하며, 해당 지역의 세부 시군구 날씨/미세먼지 직접 선택 지원.

## 개발

- Windows 10/11 x64
- .NET 8 SDK
- Visual Studio 2022 또는 호환 IDE 권장

```powershell
git clone https://github.com/LUCKYBRIDGE/knolteacher.git
cd knolteacher
dotnet restore KnolTeacher.sln
dotnet build KnolTeacher.sln -c Release
```

권장 방법:

```bat
publish.bat
```

성공 시:

```text
dist-net\놀티쳐.exe
```

## 개발 기준 문서

AI 도구나 새로운 개발 환경에서 작업을 시작할 때 다음 순서로 확인한다.

1. `AGENTS.md`
2. `docs/PROJECT_CONTEXT.md`
3. `src/KnolTeacher.Desktop/KnolTeacher.Desktop.csproj`
4. 현재 `main`, Release, PR, Actions 상태

`legacy-python/`의 문서는 과거 Python 구현 기록이며 현재 개발 기준이 아니다.

## 저장소 운영 원칙

- 신규 작업은 작업 브랜치에서 수행하고 PR로 `main`에 반영한다.
- `main`에 직접 기능 코드를 작성하지 않는다.
- 빌드 산출물(`.exe`, `.dll`, `bin/`, `obj/`, `dist-net/`)은 커밋하지 않는다.
- 학생 개인정보와 로컬 설정 파일은 저장소에 커밋하지 않는다.
- 기능 변경 시 README와 프로젝트 컨텍스트가 실제 구현과 어긋나지 않는지 확인한다.
