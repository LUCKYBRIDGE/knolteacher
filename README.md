## 📥 다운로드 및 빠른 시작 (Quick Start)

### 1️⃣ 다운로드
👉 **[🚀 최신 버전 놀티쳐 데스크.exe 다운로드하기 (GitHub Releases)](https://github.com/LUCKYBRIDGE/teachermate/releases/latest)**

### 2️⃣ 실행 및 설치
* 별도의 복잡한 설치 과정이나 Python 설치가 **전혀 필요 없습니다.**
* 다운로드받은 **`놀티쳐 데스크.exe`**를 바탕화면에 두고 더블 클릭하여 바로 실행하시면 됩니다.

### 3️⃣ 자동 업데이트 지원
* 한 번 다운로드받아 두시면, 향후 새 버전이 출시되었을 때 앱 내부의 **`[🔄 최신 업데이트 확인]`** 버튼 클릭 한 번으로 웹 브라우저를 열 필요 없이 1초 만에 최신 버전으로 자동 덮어쓰기 업데이트됩니다.
* 새 버전으로 업데이트되더라도 선생님께서 설정하신 **시간표, 학교 정보, 바로가기 사이트 목록, 테마 등은 100% 안전하게 영구 보존**됩니다.

## 🌟 핵심 기능 소개

### 1. 📅 오늘의 일과 & 실시간 급식 2단 대시보드
* **나이스(NEIS) 공식 Open API 연동**: 전국 17개 시·도 교육청의 모든 초·중·고등학교 검색 및 실시간 시간표/급식 연동.
* **수업 교시별 스마트 알람**: 수업 시작 전 5분(설정 가능) 사전 차임벨 알림 지원.
* **대한민국 법정 공휴일 자동 인식**: 공휴일에는 수업 일정이 자동으로 제외됩니다.
* **오늘의 점심 급식 식단표**: 중식 메뉴 목록, 칼로리, 알레르기 유발물질 번호 표기.

### 2. ✏️ 화면 전체 판서 & 5대 스마트 교실 수업 도구
* **투명 스크린 오버레이 판서**: 어떤 화면(나이스, 유튜브, PPT, PDF, 웹 브라우저 등)이 떠 있어도 그 위에 즉시 부드러운 형광펜/펜/도형/지우개로 자유롭게 판서.
* **5대 교실 수업 도구 (All-in-One)**:
  * ⏱️ **활동 타이머 & 스톱워치**: 1분/3분/5분 프리셋 및 알림음 지원
  * 🎲 **학생 번호/이름 무작위 뽑기**: 롤링 애니메이션 및 중복 제외 지원
  * 🎡 **돌려돌려 돌림판 (Roulette)**: 모둠, 벌칙, 보상, 미션 등 자유 항목 회전 룰렛
  * 🪜 **짜릿한 사다리타기 (Ghost Leg)**: 무작위 사다리 발판 생성 및 경로 추적 애니메이션
  * ⚾ **아케이드 핀볼 추첨기 (Plinko)**: 핀을 통통 튕기며 슬롯으로 골인하는 물리 핀볼 추첨
* **올웨이즈온 플로팅 퀵바**: 모니터 구석에 둥둥 떠다니는 미니멀 퀵바(원형 뱃지 축소 지원)로 모든 도구를 원클릭 호출.

### 3. 📝 4세대 나이스(NEIS) 엑셀 안전 자동입력
* **행동특성 및 종합의견 / 창의적 체험활동 / 교과별 세부능력 1초 자동입력**:
  * 엑셀 파일 업로드 시 학생 번호와 이름을 **자동 검증**하여 오입력을 원천 차단.
  * 복잡한 수작업 복사-붙여넣기 없이 안전하게 나이스 웹 화면에 정밀 입력.

### 4. ⚙️ PC 전원 관리 & 주요 교육 사이트 원클릭 런처
* **퇴근 및 컴퓨터 자동 꺼짐 예약**: 월~금 퇴근 시간 자동 종료 예약 (공휴일 자동 제외).
* **교사용 필수 사이트 바로가기**: 놀퀴즈(pinky-ne.com), K-에듀파인/업무포털, 강원SW인증키, 강원아이로, 아이스크림, 인디스쿨, 캔바 등 기본 탑재 + 맞춤형 사이트 자유 추가/수정.

### 5. 🎨 감성적인 3대 테마 & 시력 보호 디자인
* **따뜻한 웜 베이지 (Warm Beige - 기본 권장)**: 교실 모니터에서 눈이 편안한 최고급 크림 베이지 톤.
* **다크 모드 (Dark Indigo)**: 야간 및 어두운 환경 최적화.
* **모던 라이트 (Clean Light)**: 화사하고 깨끗한 표준 라이트 톤.

## 🛡️ 데이터 안전 및 개인정보 보호
* **글로벌 영구 저장소 (`~/.knol_teacher_desk`)**:
  * 모든 설정(시간표, 학교명, 개인 바로가기 목록)은 사용자의 로컬 컴퓨터(`C:\Users\<계정>\.knol_teacher_desk\`)에만 안전하게 보관됩니다.
  * 외부 서버로 선생님의 개인정보나 학생 정보가 일절 유출되지 않습니다.
