놀티쳐 v3.0.9 업데이트

수업 중 더 편리해졌어요
- 팝업으로 여는 도구는 왼쪽 클릭 시 교사 화면, 오른쪽 클릭 시 두 번째 화면에 열 수 있습니다.
- 놀보드 위젯 버튼은 일반 창을 여는 버튼과 은은하게 구분되어 어떤 방식으로 실행되는지 더 쉽게 알 수 있습니다.
- 일정 등록 화면을 정리해 제목, 날짜와 시간, 알림, 메모와 준비사항을 한 흐름에서 입력할 수 있습니다.

놀보드 사용이 더 안정적이에요
- 위젯을 열고 닫거나 다시 열 때 동작이 더 안정적으로 이어집니다.
- 위젯 이동과 크기 조절이 전자칠판에서도 더 편하게 동작하도록 개선되었습니다.
- 점수판과 알림장 등 일부 위젯의 로컬 저장 안정성을 높였습니다.

업데이트가 더 확실해졌어요
- 화면에 표시되는 버전 숫자가 실제 실행 중인 놀티쳐 버전과 일치합니다.
- 업데이트 파일을 확인한 뒤 기존 놀티쳐를 새 버전으로 교체하고 자동으로 다시 실행합니다.
- 업데이트가 끝난 뒤 새 버전으로 실행되었다는 안내를 확인할 수 있습니다.
