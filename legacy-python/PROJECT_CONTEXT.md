# DEPRECATED — Legacy Python Project Context

이 파일은 과거 Python/CustomTkinter 기반 놀티쳐 구현의 기록 위치를 유지하기 위해 남겨 둔다.

## 현재 상태

- **현재 주력 구현이 아니다.**
- 현재 앱은 **C# / .NET 8 / WPF** 기반이다.
- 현재 개발 기준은 저장소 루트의 `AGENTS.md`와 `docs/PROJECT_CONTEXT.md`이다.
- 이 디렉터리의 Python 소스와 빌드 스크립트는 역사적 참고 및 필요 시 마이그레이션 비교용이다.

## 금지

새로운 AI 개발 세션이나 개발자가 이 파일의 과거 Python 명령을 현재 프로젝트의 빌드·배포 지침으로 사용하면 안 된다.

현재 작업을 시작하려면 다음을 확인한다.

1. `/AGENTS.md`
2. `/docs/PROJECT_CONTEXT.md`
3. `/src/KnolTeacher.Desktop/KnolTeacher.Desktop.csproj`
4. GitHub의 현재 `main`, Release, PR, Actions 상태

Python 버전의 세부 구현이 필요한 경우 Git 기록 또는 이 디렉터리의 소스 파일을 직접 확인한다.
